# Atomic direct-faithfulness preload composition (2026-10-21)

## Purpose

Close the integration gap between the current three-record candidate/sampler/clock-presence preflight and the signed phase-1 live processor-batch preflight. The intended check must establish that both branches refer to the same ordered source cohort and that the signed processor manifest's relevant pins match the actual CPU tensors. It must remain a diagnostic, not an execution authorization.

## Implementation and checks

Added `scripts/qta_direct_faithfulness_atomic_preload.py`, which snapshots ordinary inputs, preserves only the three typed `FrozenBatch` references, reruns both existing leaf gates, and returns either an aggregate-only pass or an atomic zero-row block. The wrapper compares the candidate bridge's ordered tokens/source hashes with the stage-1 pins and live rows; checks review/source byte identity across branches; checks the signed processor manifest against the candidate protocol digest; and binds each row's token hash, batch/source digests, processor/tokenizer/sampler pins, input-ID digest, video grid and the runtime descriptor SHA to the candidate pins, signed runtime bytes and live tensors. Live batches are rehashed after the validators. During a full synthetic signed-receipt integration attempt, the existing verifier path failed to forward the required v2 expected row pins and protocol hash into `verify_phase_freeze_receipt`. Fixed this by threading the optional v2 pins through `qta_prebaseline_transaction_preflight.py` and `qta_signed_prebaseline_live_batches.py`; the wrapper supplies them only after candidate rows and live tensors have been cross-bound. The test now creates and verifies a real synthetic Ed25519 phase-1 receipt and composes it with the candidate bridge. Added tests cover reordered/mismatched cohorts, leaf failure, mutation, aliases, source-map shape differences, processor/runtime-pin mismatch, float input IDs, and the end-to-end signed-v2 composition.

On 2026-10-21, the focused wrapper test passed, including a real synthetic signed-v2 transaction composition. The broader command `PYTHONPATH=scripts .venv/bin/python -m unittest scripts.test_qta_direct_faithfulness_atomic_preload scripts.test_qta_prebaseline_transaction_preflight scripts.test_qta_prebaseline_live_batch_binding scripts.test_qta_processor_batch_digest_manifest_v1 -v` passed **112 tests** in 55.9 seconds (including imported fixture test classes). `compileall` and `git diff --check` passed in the same command chain.
