# Prespecified plan: causal self-localization (CSL), stage B of the correction plan (written 2026-10-24, before any CSL run)

## Why
The user pointed out (2026-10-24) that annotation-based evidence cropping is an oracle hint, so it is only an upper bound; a deployable correction must be annotation-free. SGC (attention-mass selection) is the first annotation-free
selector (plan: 2026-10-23_self_guided_cropping_plan.md, not yet run). Attention is a routing signal, not a causal one. CSL asks the same question with a causal score taken from the model's own forwards:
**does the answer margin drop most when the video->text pathway loses the groups that actually carry the evidence, and can that selection beat a random choice of the same budget?** Label-free; scope = answer margin on NExT-GQA, not explanation faithfulness.

## Method (all parameters fixed now; no tuning)
- Per video: baseline forward; then 16 leave-one-group-out knockouts: text rows T (between the last video token and the final position) cannot attend to the keys of temporal group g (mask set to -inf, layers 6-20 = the WP0/WP1 video->text band; WP1 verified this edge).
- Causal score c_g = self-margin(baseline) - self-margin(knockout g), where self-margin = log-prob of the baseline-predicted option minus the best other option (label-free: no annotation and no gold label in the selector); the gold-based margin is used only for the outcome endpoint.
  Correction before any run: the first runner draft computed c_g from the gold margin, which would leak the answer into the selector; it was replaced by the self-margin (scripts/run_csl.py).
- Selection: top-|A| groups by c_g (matched budget, "csl") and top-4 (annotation-free budget, "csl4"). Arms in keep mode as in SGC: oracle, random (disjoint hash sham), csl, csl4, random4. Forwards per video: 1 + 16 + 5 = 22.
- Cohorts, endpoints, decision rules, Holm over (P1 = csl - random, P2 = csl4 - random4), TOST, the positive-control logic (oracle - random >= 0.3 nat) and the replication rule are identical to the SGC plan; the SGC and CSL receipts use the same cohorts so selectors can be compared per video.
- Localization diagnostic: overlap of the top-|A| groups with A versus the hypergeometric chance level; top-1 hit rate versus chance. Prespecified gate for "localizes" = mean overlap >= 1.5 x chance (stage B of docs/correction_planning_20261024.md used 2x as an example; 1.5x is the minimum considered practically useful given N ~ 350; both reported).
- Order: SGC val smoke (n=3), SGC val, then CSL smoke (n=3), CSL val, then test replication of whichever selector supported. Expected CSL workload: ~22 forwards x 350 videos, about 2-3 h.

## Limits
The oracle count |A| leaks the budget in csl/random (not csl4/random4); knockout of one of 16 groups can be small relative to margin noise; one model and dataset; val exposure as in SGC; annotation intervals are uncalibrated.

## Result on the val prefix (N=150, 2026-10-25; one prespecified analysis; receipt csl_val_full_20261025_90.json local-only)
Smoke passed (n=3). Full run: 150/150 recorded, 0 excluded, 3,300 forwards (22/video), about 5.8 h.
- P1 csl - random (matched budget, disjoint comparator): +0.756 nat [+0.308, +1.203], Holm p=0.0022 -> supported. P2 csl4 - random4 (annotation-free budget, non-disjoint comparator): +0.407 [+0.007, +0.807], t p=0.046, Wilcoxon p=0.019, Holm p=0.046 -> supported by the rule, but marginal (the interval's lower bound is at 0).
- Reference: oracle - random +0.699 (supported); csl - oracle +0.057 [-0.343, +0.457] (no detectable distance to the oracle); arm - baseline: oracle +0.599, random -0.100, csl +0.656, csl4 +0.693, random4 +0.286.
- Exploratory (not prespecified): csl - random4 +0.371 [-0.000, +0.741]; accuracy flips vs baseline (n=150; baseline correct 96): csl4 correct->wrong 3, wrong->correct 7 (McNemar p=0.34), random4 17/18, oracle 15/20, csl 7/9; correct counts: baseline 96, oracle 101, csl 98, csl4 100, random4 97.
- Localization is only modestly above chance: mean overlap 1.213 vs 1.031 by chance (1.18x; prespecified 1.5x gate not met), top-1 hit 0.333 vs 0.218 (1.5x); by budget it is above chance for |A|=1-3 and at chance for |A|=4.
- Interpretation (inference): the causal selector is far better than the attention selector (SGC: P2 +0.11 val, -0.06 test) on the margin endpoint, mostly because it keeps the groups the model's own prediction depends on (few correct answers are broken: 3/96 for csl4), not because it finds the annotated evidence (overlap near chance at larger budgets). The gain over a non-disjoint random 4-group crop is marginal at N=150. It is a self-consistent crop, not an evidence localizer.

## Replication on the test cohort (prespecified now, before any CSL test run; queued first)
Cohort: the SGC-test / Stage 2b cohort, N=278 (all 278 recorded in the SGC test run, same screens and manifest), same runner, 22 forwards/video (about 10 h). Decision rule fixed now: the replication target is **P2 (csl4 - random4, annotation-free budget, non-disjoint comparator)**, supported iff t, sign-flip and Wilcoxon p < 0.05, mean >= 0.3 nat and Holm p < 0.05 over (P1, P2) as in the SGC analysis; P1 is reported with the comparator caveat. Secondary (descriptive): csl4 - baseline, McNemar exact test of csl4 accuracy versus baseline, csl - random4, localization versus chance. A non-supported P2 is reported as not replicated (N=278 power for 0.4 nat at SD ~2 is about 0.6 or lower).
