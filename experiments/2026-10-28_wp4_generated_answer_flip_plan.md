# Plan (not yet implemented or run): WP4 generated-answer flips under cited-interval knockout and keep (written 2026-10-28, before any WP4 run)

## Why
WP2/WP3 measure dependence of the forced-choice readout (log-probs of the five option letters at one position) on the interval the model cites. A reviewer concern from the base paper (option-format artifact) and the faithfulness definition both point to the generated answer that accompanies the citation: if the model writes "Answer: C. Time: 3-6", does removing 3-6 change the answer it then writes, more often than removing an equal-count sham? WP4 uses the same generation prompt as WP2 and measures flips of the generated letter (a discrete, decision-level endpoint) instead of margins.

## Design (fixed now)
- Cohort: WP2 test cohort (N=278 recorded; analysed set = valid citation) first; WP2 val cohort second, each analysed once, not pooled.
- Per video (greedy decoding, max 40 new tokens, same prompt/parser as WP2): (1) baseline generation -> letter L0 and cited groups C; (2) generation with the video->text pathway of C knocked out (layers 6-20, the WP1/WP2 edge); (3) the same with an equal-count disjoint hash sham S; (4) generation with a whole-video video->text knockout as the positive control. 4 generations/video, each ~40 tokens with the knockout hook active for every decoding step (the hook masks are position-based; verified at implementation that the mask is applied to the prompt prefill and to later steps via the full-length key mask without KV cache re-use bugs; use_cache must be handled explicitly and tested on 3 videos with the knockout effect checked against the WP2 forced-choice change).
- Endpoint: flip indicator F = 1 if the generated letter differs from L0 (unparseable generations count as a flip and are also reported separately). Primary: paired difference in flip rate (cited minus sham) with exact McNemar on discordant pairs; supported iff exact McNemar p < 0.05 and the difference >= 5 percentage points (justification before the run: the baseline-wrong/-right share near the decision boundary in WP2 is about 6% of videos within 0.3 nat, so a smaller flip difference would be inside the measurement noise of the readout). Positive control: whole-video knockout flip rate - sham flip rate >= 20 points, else nulls are uninformative.
- Secondary (descriptive): flip rate among baseline-correct vs baseline-wrong; accuracy of the knockout generations; agreement of the generated letter with the forced-choice readout at baseline.
- Workload: 4 generations x ~40 tokens x 278 videos; with HF generate at ~1 s/token on this setup (to be measured in the smoke) roughly 3-4 h per cohort; smoke n=3 first and timing is reported before queuing the full run.

## Limits
Greedy decoding gives one sample; flips can reflect numerical instability (bf16, sdpa) rather than dependence, so the sham flip rate is the noise baseline; a zero-intervention repeat of the baseline generation will be run on the first 50 videos as the determinism check (flip rate must be ~0, otherwise the endpoint is unusable); one model and format; the citation may be uncalibrated; label-free (no gold label in the endpoint).

## Implementation and start (2026-10-28)
Implemented scripts/run_wp4_generated_flip.py (from the WP2 runner; per video: baseline generation, determinism repeat for the first 50 videos, then greedy generations with prefill-only video->text knockout, layers 6-20, of cited / equal-count sham / annotation / whole video), scripts/qta_prefill_knockout.py (the knockout edit applies only when the query length equals the prompt length; decode steps with the KV cache pass through, so generated tokens read the video only through the knocked-out prompt rows; the layer-call audit requires exactly one prefill hit per layer), scripts/analyze_wp4_generated_flip.py (primary exact McNemar on cited-vs-sham flips, gates: diff >= 5 points, positive control >= 20 points, determinism repeat flip <= 2%), CPU tests (pass when called directly). Smoke n=3 (test): 18 generations in about 122 s, determinism repeat identical in 3/3, no hook errors, decode pass-through calls observed (the knockout is not applied during decoding by design). Workload estimate from the smoke: ~5-6 generations/video, ~30-40 s/video, about 2.5-3 h per cohort. Queue n (tag 20261028n): wp4test (278) then wp4val (300), each smoke -> full -> analysis, one analysis per cohort, no pooling. Design note recorded before any result: the knockout acts on prefill only; a knockout that also covered the generated tokens' direct video->last edge was not tested (WP1 found that edge ~0).

## Result on the test cohort (278 recorded, 13 excluded, 265 analysed; 2026-10-27 18:50 UTC; one prespecified analysis; receipt wp4test_full_20261028n_wp4test.json local-only, results/wp4test_summary_20261028n_wp4test.json)
Determinism: the unmodified repeat generation matched the baseline in 45/45 videos (flip rate 0.0). Positive control passed: whole-video knockout flips 35.8% vs sham 3.0% (diff +32.8 points, 90 vs 3 discordant). Primary: cited-interval knockout flips the generated letter in 7.9% of videos vs 3.0% for the equal-count sham, difference **+4.9 points**, discordant 19 vs 6, exact McNemar p=0.0146 -> by the prespecified rule (diff >= 5 points AND p < 0.05) **not supported / inconclusive** (the difference is 0.1 point under the threshold; the p-value is below 0.05). Reference: annotation knockout 7.5% vs sham 3.0% (15 vs 3, p=0.008). Exploratory splits (not prespecified, small n): baseline-correct (n=205) cited 5.4% vs sham 2.0% (10 vs 3, p=0.092); baseline-wrong (n=60) 16.7% vs 6.7% (9 vs 3, p=0.146). Interpretation (inference): removing the cited interval changes the generated answer more often than removing a sham interval (a small absolute effect, about 5 points, consistent with the margin effects of ~0.3 nat in WP2), while removing the whole video changes it in a third of the videos; the effect is on the generated decision, so it is not an artifact of the option-letter readout, but it is small and sits at the prespecified threshold. The val cohort is running and will be analysed once, not pooled. Scope: one model and citation format; not a faithfulness verdict.

## Result on the val cohort (300 recorded, 11 excluded, 289 analysed; 2026-10-27 21:48 UTC; one prespecified analysis, not pooled with test; results/wp4val_summary_20261028n_wp4val.json)
Determinism: unmodified repeat identical in 48/48. Positive control passed (whole-video knockout flips 43.3% vs sham 4.8%, +38.4 points). Primary: cited-interval knockout flips the generated letter in 6.2% vs 4.8% for the sham, difference **+1.4 points**, discordant 14 vs 10, exact McNemar p=0.54 -> **not supported** (below the 5-point threshold, not significant). Reference: annotation vs sham 7.6% vs 4.8% (16 vs 8, p=0.15). Exploratory splits: baseline-correct (n=210) 2.9% vs 2.9% (5 vs 5); baseline-wrong (n=79) 15.2% vs 10.1% (9 vs 5, p=0.42).
Across cohorts (inference): test +4.9 points (p=0.015, 0.1 under the threshold) and val +1.4 points (p=0.54) do not agree; the generated-answer flip endpoint shows no reliable cited-versus-sham difference, although the whole-video control flips 36-43% of generations. So the decision-level effect of removing the cited interval is at most a few points and not reproducible at N~270-290 per cohort; the margin-level effects in WP2 (about 0.3 nat) are not matched by a detectable change in the generated letter. Scope: greedy generation, one model, one citation format, prefill-only knockout; not a faithfulness verdict.
