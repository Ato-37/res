# QTA actual-PTS/scalar-FPS mapping marker binding (2026-10-18)

## Purpose

The processor batch mapper performs a fail-closed comparison between the
review-interval group assignment derived from actual decoded PTS and the
assignment implied by the processor's scalar FPS grid. A code audit found that
the later row adapter omitted the mapper's explicit pass marker, allowing a
downstream structural join to consume a projected processor row without
requiring evidence that this consistency check had been requested and passed.

## Change and checks

Updated `scripts/qta_prescore_processor_row_adapter.py` to accept only
`processor_uniform_grid_assignment_check="passed_actual_pts_and_scalar_fps_group_sets_equal"`
and preserve that field in its projected row. Updated
`scripts/qta_prescore_mapping_binding.py` to require the same exact marker in
each of the three processor rows and include it in the row-binding digest.
Missing, `not_requested`, and mismatch marker values now block the join before
any model branch can run. The existing mapper already requests the underlying
check with `require_processor_uniform_grid_assignment=True`.

This change checks propagation of a mapper result field. The adapter and join
still accept caller-supplied dictionaries and do not authenticate that the
marker was honestly produced; verification from original batch and PTS bytes
remains necessary in any future phase verifier.

Focused processor-adapter, mapping-binding, and plan-aggregate suites passed
**27/27**. They include missing/not-requested/mismatch rejection, a successful
non-authorizing three-row join, processor-group checks, and aggregate plan
checks. The mapper's PTS/FPS regression tests were also run in a separate
focused command and passed as part of **30/30** combined mapper/adapter tests.
The first full-suite run exposed seven downstream failures because the shared
synthetic cohort fixture omitted the newly required mapper marker. The
production gate correctly rejected it. The fixture now models the current
mapper output, and the adapter/binder/aggregator plus both synthetic-cohort
integration suites passed **35/35**. The final full `scripts` suite passed
**1,622/1,622** in **38.599 seconds**. Expected negative-path fixture
messages and Transformers deprecation warnings appeared. `git diff --check`
and Python compilation passed. An independent auditor reviewed the adapter,
mapping binder, and tests; it verified the exact marker is generated by the
existing mapper, required by both layers, included in the row digest, and
does not grant model/score authority. No media, GPU, or human-review artifact
was used.

## Interpretation and limits

This closes a structural omission between the actual-PTS/FPS mapper and the
pre-score row-binding layer. It prevents a missing or failed marker from being
silently dropped by these two functions. It does not prove that a person
reviewed the interval, that the PTS/FPS values are authentic, that claim
evidence is semantically valid, or that a score is authorized.
