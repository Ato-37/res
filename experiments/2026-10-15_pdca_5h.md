## Bounded novelty check

The primary-source check of [INFACT (2026)](https://arxiv.org/abs/2603.11481)
confirms it evaluates video QA under visual degradation, evidence corruption,
and temporal shuffling/reversal with Resist Rate and Temporal Sensitivity
Score. Its published description does not indicate a human-mapped explanation
claim-to-frame test or a temporally matched-control fixed-choice-margin
estimand. [EDCT (2025)](https://arxiv.org/abs/2510.00047) is closer at the
concept level: it extracts concepts from a target VLM's explanation and tests
them using edited images and judge-scored answer/explanation consistency. Its
reported setup is image OK-VQA, generated counterfactual edits, and LLM-assisted
scoring, not temporal frame masks or matched controls. This is a bounded
comparison of two papers, not a systematic literature review. It rules out a
broad novelty claim about explanation-driven VLM interventions; any narrower
novelty claim still needs a fuller search and direct method comparison.

A second targeted search found closer video-specific prior work. [VCSR
(ACM MM 2023)](https://arxiv.org/abs/2305.04224) explicitly selects causal
segments and frames for VideoQA and estimates intervention effects within a
trained architecture. [CRA (CVPR 2025)](https://arxiv.org/abs/2503.07635) is
closer still: it jointly predicts an answer and the time interval serving as
its rationale, and uses a front-door intervention with grounding and QA
outcomes on NExT-GQA/STAR. These methods make any broad novelty claim about
causal frame selection, temporal grounding, or video-QA evidence interventions
untenable. Their stated goal is to train/develop a VideoQG model, whereas the
current plan targets an external behavioral audit of an existing pretrained
VLM's own explanation claim using reviewer-mapped frames, matched temporal
controls, and a frozen-choice score. This distinction is a method comparison,
not yet a verified novelty claim.

[Causal-VidQA (CVPR 2022)](https://arxiv.org/abs/2205.14895) adds an explicit
evidence-reasoning/explanation question category with reasons for some
commonsense tasks, but its abstract does not describe an intervention test of
the target VLM's rationale. [CausalPhys (KDD 2026)](https://arxiv.org/abs/2606.05966)
is a direct rationale-evaluation competitor: model rationales are judged
against expert causal graphs for entity faithfulness, relation awareness, and
description correctness over image/video physical-reasoning questions. The
published metrics assess semantic alignment to gold structure; they do not
appear to intervene on the same model input at the cited evidence location.
This project therefore cannot claim to be the first to assess causal rationale
faithfulness in video VLMs. The possible differentiator is measuring causal
dependence of the target model's own claim-mapped evidence with an external
frame intervention and a dose-matched control, rather than scoring semantic
rationale correctness alone. The search is targeted, not exhaustive, and the
causal interpretation of black/blur masks remains limited by OOD perturbation.

## Resampling provenance repair

An independent statistical audit found no arithmetic error in the legacy
percentile-bootstrap or Monte Carlo sign-flip calculations. It did find that
the output omitted the configured draw count, so a stored seed did not fully
specify the run's resampling precision. The input's one-row-per-video property
also remains unverified; no untracked manifest or item-level result was read,
so this audit makes no claim that the historical run violated independence.

The exploratory runner output schema is now version 3 and records
`bootstrap_draws`, the Python version/implementation, and the deterministic seed
assignment for all, baseline-correct, baseline-incorrect, and interaction
summaries. The scoped publisher now exposes `--bootstrap-draws` and records the
value in its run manifest; a CPU test verifies forwarding. A CPU test fixes the
seed schedule. Focused necessity-choice tests pass (18), publisher command test
passes (1); full `scripts/` discovery passes (564); byte-compilation and
`git diff --check` pass. Expected
CLI failure-path messages appeared inside the test suite, but discovery exited
successfully. This additive provenance change does not alter any estimate or
resampling algorithm. The minimum 100 draws remains accepted; tail quantiles
and Monte Carlo p-values at that minimum have coarse simulation resolution, so
the effective count must be reported and interpreted accordingly.
