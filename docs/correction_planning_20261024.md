# 「補正」を実現するための計画(検討メモ、2026-10-24)

目的: 診断(モデルが証拠区間をどの経路で使うか)が得られたので、次の段階として、**内部介入で回答や証拠への依存を改善する「補正」**の可能性を、現実的に検討する。本メモは計画で、実装・実験は承認後に行う。

## 1. いまわかっていること(補正に関わる事実)
| 事実 | 出典 | 補正への意味 |
|---|---|---|
| 証拠フレームの情報は、中層(6〜20 層)の動画 → 質問・選択肢の経路を通って回答に届く。直接経路(動画 → 最終位置)は使われない | WP0、WP1(事前登録、陽性対照合格) | **介入の標的(層・行)が定まった** |
| 注釈の証拠区間だけを残す(それ以外のキーを抑制する)と、素のモデルより margin が上がる(+0.56 開発、+0.64 test)。**回答の正誤では、プールすると、正→誤 12 件に対して誤→正 26 件(正味 +14/203 = +6.9 ポイント、探索的)**。同数のランダム区間では、正味 −3 | Stage 1・2(探索的に再集計) | **oracle(注釈を使う)の上限として、補正の余地はある** |
| ただし test(N=80)では、ランダム区間を残しても margin が上がり(+0.46)、注釈区間との差は +0.18(結論なし) | Stage 2 | 証拠特異な部分は、未確定(Stage 2b で判定予定) |
| 証拠区間のキーを**強める**介入は、素のモデルより良くならない(注釈 − baseline ≤ 0) | key-bias の用量反応(2 コホート) | 「強調」は有効でない |
| 対照的デコーディング(全入力の出力 − 証拠を遮断した出力を増幅)は、oracle の証拠を使っても、**正答率がほぼ変わらない**(69.6% → 70.5%、直した 4 件、壊した 3 件、探索的) | WP1 のデータでのオフライン見積もり | この方式は、有望ではない |
| 注釈なしで証拠を選べるかは**未測定**(SGC で測る予定。成功の見込みは低め) | — | **最大のボトルネック** |

## 2. 「補正」の定義(3 水準)と、現実性
| 水準 | 内容 | 評価指標 | 現実性(私の推定) |
|---|---|---|---|
| **L1: 回答の補正(oracle の上限)** | 注釈を推論時に使い、証拠区間に注意を集中させる | 正答率、margin(ランダムな同数の対照との差) | **中〜高**(正味 +7 ポイント。ただし証拠特異かは未確定) |
| **L2: 注釈なしの補正** | モデル自身が証拠区間を推定して、同じ介入を行う | L1 と同じ指標 + 証拠の局在精度(注釈との重なり) | **低〜中**(推定が、偶然を超えるかが鍵) |
| **L3: faithfulness の補正** | 回答が、証拠に依存する度合い(WP1 型の遮断で測る)を高める。正答率は下げない | 遮断による margin 低下の大きさ(証拠 − ランダム)の変化 | **低**(強調では、改善しなかった。指標が、介入と循環しやすい) |

**現実的な到達点の提案**: **L1(上限)を確立し、L2 で「注釈なしで、その何割に届くか」を測る。L3 は、探索的**に留める。

## 3. 具体的な段階計画(各段階にゲート)
各段階の判定基準は、データを見る前に固定します(閾値は 0.3 nat などの根拠つき)。

### 段階 A: oracle の上限の確定(進行中)
- Stage 2b(N=278)と、Stage 2 との統合解析(事前登録済み)。
- **ゲート**: 統合で、注釈残し − ランダム残しが、0.3 nat 以上で確証されるなら、「証拠特異な補正の余地がある」。されなければ、「文脈を減らす効果」が主で、局在の良し悪しは重要でない(L2 の意義が薄れる)。

### 段階 B: 注釈なしで、証拠を局在できるか(新規、最優先)
2 つの方法を、同じ指標で比べる。
1. **注意による選択(SGC、実装済み、待機中)**: 10〜18 層の動画 → 質問の注意の質量が、高いグループを選ぶ。
2. **因果的な自己局在(CSL、新規)**: 動画のグループを 1 つずつ、動画 → 質問(中層)で遮断し、**margin の低下が大きいグループ**を、重要と判定する(16 個 + baseline の 17 回の forward / 動画、約 1.5 時間 / 100 動画)。注意より、因果的で、faithful な信号が期待できる。
- **指標**: 上位 k グループと注釈の重なり、top-1 のヒット率(偶然の水準との比較、事前に閾値を固定。例: 偶然の 2 倍以上)。
- **ゲート**: どちらも偶然を超えなければ、L2 は断念し、報告は「証拠の局在は、モデルの自己信号では難しい」という診断結果にする。

### 段階 C: 注釈なしの補正(段階 B を通った場合のみ)
- 選んだグループを残す cropping を、**ランダムな同数の対照**、baseline、oracle と比べる(margin と、正答の遷移)。
- **不確実性による選択的適用**(新規): baseline の margin が小さい動画だけに適用する(閾値は事前に固定。注釈なしで決められる)。**探索的な再集計**では、baseline の margin が負の動画で cropping の効果が大きい(+1.6 nat)が、これは**平均への回帰**も含むため、ランダム区間との差(+0.45)で見る必要がある。
- **ゲート**: 選択的・非選択的のいずれかで、事前の基準を満たすか。

### 段階 D: 一般性(時間があれば)
- 別のモデル(例: Qwen2.5-VL の小さい版や別系統)、または別データでの再確認。16GB VRAM の制約がある。

### 段階 E: 説明との接続(L3、探索的)
- 補正後のモデルで、短い説明を生成させ、WP1 型の遮断で、説明が引用する証拠への依存を測る。人手の確認は、最大 10 件の動作確認に限る。

## 4. 統計的な課題(率直に)
- **正答率の改善は、検出が難しい**: 正誤が変わる動画は一部(oracle で約 19%)。+3 ポイントの差を検出するには、N が 1,000 以上必要になりうる。→ 主指標は、**margin(連続量)**にして、正答率は、補助にする。
- 開発段階の効果は、再現で縮む(+0.66 → +0.18)ことがあった。**探索と確証のコホートの分離**を維持する。
- test の適格な動画は約 54% のみ。N の確保に限りがある。

## 5. 成功の見込み(私の推定、参考)
| 段階 | 通過の見込み |
|---|---|
| A: oracle の証拠特異な効果の確証 | 40〜50% |
| B: 注釈なしの局在が、偶然を超える(CSL または SGC) | 50〜60%(注意よりも CSL の方が見込みが高い) |
| C: 注釈なしの補正が、ランダム cropping を、基準を超えて上回る | 10〜20% |
| 全体(L2 まで到達) | 約 5〜10% |
| 「L1 の上限の確立 + L2 の到達割合の測定」という成果の成立 | **高い(80% 以上)** |

**要点**: 「補正を実現した」という強い主張が成り立つ確率は低いが、「**補正の上限と、注釈なしで届く割合を、事前登録で測った**」という結果は、ほぼ確実に得られ、これ自体が貢献になる。
