# 土台とする論文と拡充の方針(検討メモ v2、2026-10-23)

目的: 「論文 1 本を土台に、それに対する拡充を行う」構成に、これまでの成果と今後の作業を載せる。**v2 では、土台を top 会議で査読済みの論文に絞って選び直した**(v1 は Findings 採択の Menzat et al. を推奨していたが、ユーザー指示で取り下げ。同論文は関連研究に格下げ)。どの論文を土台にするかの最終判断は指導教員・本人。内容は 2026-10-23 に arXiv・会議の公式ページで確認した範囲(*Map the Flow* の本文の末尾約 55k 文字は未読)。

## 1. 土台の選定基準
(a) top 会議(ICLR/CVPR/ICML/NeurIPS/ACL/EMNLP main など)で査読済み、(b) 問いが本研究(動画VLMの内部・証拠依存・faithfulness)に近い、(c) コード・データが公開、(d) 著者が示す限界・未着手の部分に、拡充の余地がある、(e) 既存の資産で着手できる、(f) 16GB VRAM で実行できる。

## 3. 推奨: A(*Map the Flow*、ICLR 2026)を土台にする

**理由**
1. 問いと手法が最も近い: **動画VLMの内部経路を、attention knockout で因果的に調べる**。
2. top 会議(ICLR 2026)で査読済み。コード・データが公開されている。
3. **著者が評価していない部分が、本研究の資産とそのまま対応する**(本文で確認した範囲): 証拠フレーム・grounding(NExT-GQA など)の評価、ステアリング、Qwen2.5-VL、(正答サンプルのみの解析という制約)。
4. すでに得た結果(最終位置のみの介入は無効、動画後の全クエリ行で有効)は、土台の論文の経路(動画 → 質問・選択肢 → 最終位置)と整合する。**本研究は、その知見を別のモデル(Qwen2.5-VL)で、証拠区間に特化して確かめ、拡張する**位置づけにできる。

### 土台の手法と、本研究の手法の対応
| 土台(Map the Flow) | 本研究のこれまでの実装 |
|---|---|
| 因果マスクの −∞ で、動画 → 質問・選択肢 → 最終位置のエッジを遮断 | 同じ機構(注意マスクへの加算バイアス。−∞ も実装済み)。動画 → 動画後の全クエリ行 |
| 遮断で、元の予測の確率が相対的に変化 | 遮断・強化で、gold − foil の margin が変化(fp32 読み出し) |
| 動画全体・フレーム間の遮断 | **注釈(gold)の証拠区間のキーだけ** vs 同数のランダム区間(sham) |
| 阻害のみ | **強化と抑制の両方向**、用量反応、陽性対照 |
| 1 つの微調整モデル(LLaVA-NeXT-Video-FT)中心、TVBench | Qwen2.5-VL-7B(微調整なし)、NExT-GQA |

### 拡充の軸(土台 → 本研究)
1. **証拠特異性**: 土台は動画全体のエッジを遮断する。本研究は、**gold の証拠区間だけ**を遮断・強化し、同数のランダム区間と比べる(sham 分解を含む)。**【実施済み: 2 コホートで再現】**
2. **別のモデルでの検証**: Qwen2.5-VL-7B(土台は未評価)で、動画 → 質問 → 最終位置の経路を確かめる。**【一部実施: 経路の層・行の窓は、これから】**
3. **阻害から強化(ステアリング)へ**: 双方向、用量反応。回答の margin は、改善しなかった。**【実施済み】**
4. **説明の faithfulness との接続**: 経路上の介入が、生成された説明の証拠依存(動画版 CC-SHAP や、C の枠組み)にどう効くか。**【未着手】**
5. **測定の厳密さ**: 陽性対照、sham、fp32 読み出し、同等性検定、事前登録のコホート。**【実施済み】**

### 具体的な作業(WP)
- **WP0 土台の手法の再現(新モデル)**: Qwen2.5-VL-7B で、動画 → 質問・選択肢 → 最終位置の層ごとの遮断(土台の手法に沿った、層の窓つき)を実装し、元の予測の確率の相対変化を、NExT-GQA(正答サンプルのみ)で測る。土台の結論(経路の層帯)が、Qwen2.5-VL でも成り立つかを確認する。
- **WP1 証拠特異な遮断**: WP0 の各経路で、gold 証拠区間 vs sham の遮断を比べる(層帯ごとの特異性)。
- **WP2 経路に沿ったステアリング**: 有効な層帯だけに、強化バイアスを適用する(層の探索は事前登録で固定し、head/層/強度の再探索はしない)。
- **WP3 説明の faithfulness**: 説明つきの回答で、上記介入による回答と説明の変化を、自動の判定(人手は最大 10 件の動作確認)で測る。
- **WP4 統計と対照**: 事前登録、動画単位、同等性検定、閾値の根拠(0.3 nat 型の決め方)、陽性対照。

## 4. リスクと未確認事項
- 土台の論文の**本文の末尾と補遺は未読**。層の窓の設定(k=9、層の範囲は経験的に決定)や、Qwen2.5-VL への移植の詳細は、実装前に精読が必要。
- 土台は、LLaVA-NeXT-7B-Video-FT(自作の微調整モデル)が中心。Qwen2.5-VL は M-RoPE などの構造差があり、**同じ結論になる保証はない**(その差自体が、確認する価値のある結果になる)。
- 土台の論文が faithfulness や grounding を評価していない、という記述は、本文の確認した範囲での事実。補遺に該当する分析がある可能性は排除できない。
- 本研究の「証拠区間」は、NExT-GQA の注釈に依存し、時計の校正がない。人手監査は最大 10 件(動作確認に限る)。
- 新規性は、「証拠区間に特異的な、双方向の内部介入を、別のモデルで、陽性対照つきで検証した」という範囲に限る。

## 5. 確認したいこと(本人・指導教員)
1. 土台を **A(*Map the Flow*、ICLR 2026)** にしてよいか(B、C は、補強の参照として併用する)。
2. 拡充の 5 軸のうち、卒研で**必須にする範囲**(例: 1〜3 と 5 を必須、4 は発展)。
3. 人手監査は最大 10 件(確認済み)。説明の faithfulness(WP3)に、自動判定のみで進めてよいか。
