## 0. 土台とする論文と、本研究の位置づけ(提案)

本研究は、**Menzat et al.「Counterfactual Tests for Measuring Chain-of-Thought Faithfulness in Visual Language Models」(Findings of EMNLP 2026、arXiv:2609.06704、コード公開)を土台**とし、その拡充を行う構成を提案する([検討メモ](thesis_base_paper_extension_plan.md))。土台の論文は、画像の物体削除の反事実で、回答分布の変化と、説明が削除物体に言及するかの相関(vCCT)を測る。著者自身が「内部機構の解析」と「動画」を、未着手と述べている。

| 拡充の軸 | 土台 | 本研究 | 状況 |
|---|---|---|---|
| 1. モダリティ | 画像 | 動画(NExT-GQA の gold 時間区間) | 設計済み、説明の生成と言及判定は未着手 |
| 2. 介入の水準 | 入力の編集 | **内部の反事実(attention key の抑制)** | **実施済み**(陽性対照合格、2 コホートで再現) |
| 3. 介入手法の評価 | 扱わない | ステアリングが faithfulness を改善するか | 一部実施(回答 margin では改善なし) |

> 土台の論文の採用は提案で、最終判断は指導教員・本人。

## 1. 研究の問い

**動画VLMの内部(attention key)への介入は、モデルの出力が動画の特定の証拠区間へ依存する度合いを、選択的に高められるか。**
- 注意の移動や出力の変化だけを faithfulness の改善とみなさない。内部介入、出力変化、証拠への依存を別々の段階として測る。
- 人の納得感や LLM-as-judge は、確認バイアスの懸念から主指標にしない。
- 対象: Qwen2.5-VL-7B-Instruct(4bit 量子化、BF16 計算)、NExT-GQA(NExT-QA の動画に時間区間の注釈を付けたデータ)。

## 2. 設計の要点

| 項目 | 内容 |
|---|---|
| 指標 | 5択の正答 − 最有力の誤答の対数確率 margin(nat)。ラベルなしで計算でき、人手レビュー不要。 |
| 介入 | 動画の視覚 key(時間グループ)に、attention score へ加算するバイアスをかける。動画後の全クエリ行、全28層。 |
| 対照 | (a) 注釈区間と同数で重ならない、ランダムなフレーム(sham)、(b) 介入なし(baseline)。 |
| 読み出し | fp32。従来の bf16 は margin が 0.125 nat 刻みに丸められ、効果量より粗かった。 |
| 統計 | 動画を単位とする。N、閾値、主解析を、コホート選択の前に固定。同等性検定(TOST)も報告。 |
| 実用上の閾値 | 0.3 nat。判断境界付近の動画が約 5.5%、小さい効果(d=0.2)が約 0.34 nat、の 2 基準が一致([根拠](../experiments/2026-10-23_practical_threshold_justification.md))。 |

## 3. これまでの経過

1. **head の faithfulness 確認(事前登録、79 動画)**: 閾値 +0.25 nat に届かず、**負の結果**で閉じた(選択差 −0.076 nat、95% CI [−0.158, +0.007])。head/層/強度の探索は再開しない。
2. 根拠フレームを入力で隠す probe(60 動画)で、介入前に正答した 37 件に選択的な低下(約 +0.33 nat)。事後の部分群の結果で、control も視覚内容までは揃っていない。
3. 説明 claim の尤度を使う実験は、**人手レビューの要件で止まった**(正式レビュー 0 件)。claim 尤度×全域バイアスは、再現で符号が逆転した。
4. 方針を転換: **ラベルなしの設計**(gold の QA 時間注釈を使い、人手レビュー不要)に切り替えた。
5. 測定の修復: bf16 の丸め(0.125 nat 刻み)を発見し、fp32 読み出しに変更。SD が約 30% 減り、必要な動画数が半減した。
6. **最終位置のみの介入は無効**: +ln2〜+ln16 のバイアスに加え、抑制の陽性対照(×1/16、×1/256、5〜16層および全層)も効果なし。出力に作用しない介入だったため、これらの「効果なし」は、証拠依存がないことの根拠にならない。
7. **動画後の全クエリ行へ拡張**(複数クエリ版): 抑制の陽性対照が合格し、介入が出力に作用することを確認した。

## 4. 主要結果(複数クエリ版、2 つの独立した新規コホート)

N=149(コホート 1)と N=196(コホート 2、メディアの重複なし)。すべて事前登録、完了率 100%、失敗 0。図: [key_bias_forest.svg](figures/key_bias_forest.svg)

| 介入 | コホート | annotation − sham | annotation − baseline | sham − baseline |
|---|---|---|---|---|
| 抑制 −ln256 | 1 (N=149) | **−0.515** [−0.82, −0.21] | −0.332 [−0.56, −0.11] | +0.183 [+0.02, +0.35] |
| 抑制 −ln256 | 2 (N=196) | **−0.235** [−0.45, −0.02] | +0.002 [−0.17, +0.17] | +0.237 [+0.12, +0.36] |
| 強化 +ln4 | 1 | +0.207 [−0.005, +0.420] | −0.089 [−0.28, +0.10] | −0.296 [−0.47, −0.12] |
| 強化 +ln4 | 2 | +0.124 [−0.071, +0.318] | −0.097 [−0.25, +0.05] | −0.221 [−0.37, −0.07] |
| 強化 +ln16 | 1 | +0.449 [+0.055, +0.843] | −0.365 [−0.71, −0.02] | −0.814 [−1.19, −0.44] |
| 強化 +ln16 | 2 | +0.304 [−0.011, +0.619] | −0.065 [−0.36, +0.23] | −0.369 [−0.66, −0.08] |

(単位 nat、平均と 95% t 区間。事前登録の判定: 抑制の陽性対照は両コホートで基準を満たした。強化 2 用量の Holm 補正後は、どちらも有意でなかった。)

**読み取れること**
- 全クエリ行への介入で、陽性対照が動いた。最終位置のみの介入より、介入に実質的な作用がある。
- **注釈区間の key を強めても、素のモデルより margin は上がらなかった**(annotation − baseline は 4 つの強化 run で一度も正にならない)。
- annotation − sham の差の主因は、6 run 中 5 run で **sham 側の変化**。ランダムなフレームの key を強めると margin が下がり、抑制すると上がる傾向が、2 コホートで一貫している(6 区間とも 0 を除外)。

## 5. 解釈の限界(重要)

- **faithfulness の直接評価は未実施**。これは「注釈区間への依存」を測るラベルなしの指標で、説明の faithfulness そのものではない。
- 抑制のコホート 2 での再現は弱い(順位検定 p=0.127、注釈側は ±0)。
- sham は純粋な null ではない(位置・内容が異なる)。ランダムなフレームの抑制が margin を上げることから、視覚情報を減らすと有利になる面がある可能性がある(仮説)。
- 介入は極端で分布外(約 2,000 key × 約 66 行 × 28 層)。効果は重い裾を持つ(中央値は 0 付近、SD 1.3〜2.4)。
- 実用閾値 0.3 nat は、データに基づいて根拠を示したが、外部基準ではない。1 モデル・1 データセット・1 split に限る。

独立監査(別エージェント)が、6 つの結果を生のレシートから再計算し、数値の一致を確認した。表現の指摘 7 件は反映済み([統合まとめ](../experiments/2026-10-23_annotation_key_bias_consolidated_summary.md))。

## 6. 進行中の実験(結果は未確定)

仮説(事後): **注釈区間以外を抑制して証拠に注意を集中させると、margin が上がる**(attention レベルの証拠 cropping。注釈を推論時に使う oracle 上限)。
- Stage 1(開発、val の新規 123 本、−ln4 と −ln256): 実行中。基準は、主 contrast の平均が 0.3 nat 以上であること。満たさなければ仮説を棄却し、確証 run は行わない。
- Stage 2(確証、test split): Stage 1 を通過した場合のみ。詳細は [計画](../experiments/2026-10-23_evidence_focusing_steering_plan.md)。
